# AI Image_Classifier
AI Image Classifier
A beginner-friendly image classification app built with Python, Streamlit, Hugging Face Transformers, PyTorch, and Pillow.

Users can upload an image and view the top three predictions with confidence scores.

Features
Upload JPG, JPEG, or PNG images
Display the uploaded image
Classify the image using a pretrained AI model
Show the top three predictions
Display confidence scores
Model Used
google/vit-base-patch16-224
